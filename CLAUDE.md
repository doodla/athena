# athena

This repository holds Athena, an agent orchestration system written in Rust, and the record of how
it was built. This file is a front door for whoever opens the repository; it is not Athena's
contract, and Athena's own agents do not load it.

- Operator of the build experiment (a session started with the prompt `continue`): read
  `operator/HANDOFF.md` before anything else.
- Anyone else: start with `README.md`. Requirements are in `BRIEF.md`.
