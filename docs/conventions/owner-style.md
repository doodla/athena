# Owner style

How the owner wants anything written for them to read. Pages and briefs made for the owner follow it.

> Show me with big pictures and little words without witholding key details. dont use weird metaphors.

In practice:

- One screen per item. A brief holds at most 120 words of prose; the decisions page refuses a longer one.
- The recommendation comes first, in one line, in plain words.
- Use only the item's own fields. Invent no figures, such as a cost or a risk, that the item does not carry.
- Say when something is not recorded. A blank is never shown as "none".
- Plain words, no figures of speech.

The decisions page is built by `cargo run -p xtask -- site` (`xtask/src/decisions.rs`).
