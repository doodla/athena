# Enforcement map

Every rule v0 carries is either enforced by a mechanism with tests, or listed below as prose-only with a
reason (design §8). Each row names the tests that show what the mechanism blocks and what it allows.
`every_test_named_in_the_enforcement_map_exists` (xtask) checks that every test named here exists, so the
map cannot drift from the code. Live tests call real models and are opt-in (`#[ignore]`); everything else
runs in `cargo test`.

## Prose-only in v0

Each of these is a judgment or a boundary that a mechanism would not yet pay for:

- *Written for strangers*, and *evidence over assertion* in prose. They reach every job through the
  applicable defaults in the briefs and through the verifier's severity rules; no mechanism checks them.
- *Buy before build* and *design before build*: process rules, recorded in the decision log.
- *Keep v0 small*: a judgment; the design's §14 is the record.
- *Interventions are never suppressed*. Corrections, answers, and hand changes to governed content are
  captured by mechanism. Interventions that change no content (detailed instructions, overridden
  decisions, state the user carried) depend on the user recording them with `athena intervene`.
- *Pushes are regular, and published history is never rewritten*: Athena does not push in v0.
- *Executed code stays contained*: not enforced in v0. Checks, builds, and tests run with the user's
  privileges (design §7.5, §16.2).
- *Records are Athena's own*: records are not signed, and Athena writes them with the user's own rights,
  so no local check can tell them from records written by hand to look like them. The gate refuses a hand
  change dressed as a landing (M6, M7) and scores and outcomes that do not follow from a job's records
  (M27). Deliberate fabrication of consistent records still passes (design §16.2): every record of a job
  across two commits; one forged commit that lands a job Athena dispatched but never closed, as an
  interrupted `athena go` leaves it; and, with no landing, a hand-made proposal closed with `athena close`,
  whose invented forecasts then count in calibration. Each forged job shows in `athena status` as a job
  nobody asked for.
