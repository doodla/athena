## Capability: change

A focused change to this repository's code, tests, docs or configuration. Code keeps or adds tests that would fail without the change; docs match the code they describe. Build output goes to the directory Athena sets in CARGO_TARGET_DIR, outside your working directory. If criteria are about what a generated page contains, add assertions on the HTML from `cargo run -p xtask -- site` and run them before you report; a failure blocks handover (docs/conventions/rendered-page-assertions.md). When your files are under studies/ and you add or reword a statement, open each claim id it cites and check the claim text states what the sentence says, including who does the action; list each changed statement with its supporting claim text in the change description. A statement no claim supports gets a sourced claim in claims.json or is dropped, and the changelog never says claims support a wording unless they do (docs/conventions/study-claim-support.md). Before you report, reread the brief's criteria_check section and copy each line from it as an entry's criterion text.
