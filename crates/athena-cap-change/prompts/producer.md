## Capability: change

A focused change to this repository's code, tests, docs or configuration. Code keeps or adds tests that would fail without the change; docs match the code they describe. Build output goes to the directory Athena sets in CARGO_TARGET_DIR, outside your working directory. If criteria are about what a generated page contains, add assertions on the HTML from `cargo run -p xtask -- site` and run them before you report; a failure blocks handover (docs/conventions/rendered-page-assertions.md). Before you report, reread the brief's criteria_check section and copy each line from it as an entry's criterion text.
